# Track: finance

**For** students who like money, markets, saving for things, or numbers in general.

| When | What it looks like |
|---|---|
| Block 2 | **Savings planner** (`b2-savings/`): weeks to a goal → week-by-week table → several goals sorted by priority → survives typos → a live exchange rate from an API |
| Block 5 | budget data in SQLite, charts, a small web page |
| Block 7 | track project: e.g. a budget dashboard or a simple backtest of a saving rule (with an ethics note) |

Ethics: this track teaches data skills, not investing advice. No real-money trading tools.
