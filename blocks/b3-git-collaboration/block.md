# B3 Git & GitHub collaboration

**Weeks 12–14 · licence L1 · stub (the [skip test](skip-test.md) is ready)**

## Goals
You've used branches and PRs by copy-paste since Block 0 ([ADR 0016](../../docs/decisions/0016-git-by-exposure-before-b3.md)). Now learn what's going on: branches, PRs, reviewing someone else's code, issues, merge conflicts and good READMEs. Then contribute to someone else's project.

## Why it matters
Software is a team sport, and from Block 6 your "teammate" is a coding agent whose PRs you review. Git is how all of that work moves.

## Exit
A PR **merged into someone else's repo**: a peer's project, or a beginner-friendly open-source or Hack Club repo.

## Licence
L1 (Explainer): the bot can explain your code and name bug types, but doesn't write new code for your task.
