# 0013. Licences

**Status:** Accepted (default; the owner may change it before the first public push)

## Context
The curriculum should be reusable by other families and mentors but not resold. Scripts, tests and checkpoints should be freely reusable.

## Decision
- **Curriculum content: CC BY-NC-SA 4.0** ([`LICENSE`](../../LICENSE), official legal code text).
- **Code (scripts, schemas, workflows, tests, starters, checkpoints, hunt checkers): MIT** ([`LICENSE-CODE`](../../LICENSE-CODE)), copyright "splinterlearn contributors".

## Consequences
- Third-party courses we link to keep their own licences. We only link to them and never copy.
- If the owner changes the licence before publishing, supersede this ADR.
