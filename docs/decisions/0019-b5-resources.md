# 0019. Block 5 resources: CS50x weeks 7–9, with Odin Foundations for HTML/CSS/JS

**Status:** Accepted (revisit when B5's modules are written)

## Context
The task named CS50x weeks 7–9 (SQL, HTML/CSS/JS, Flask) and The Odin Project's Foundations as candidates for Block 5. Both were checked on 2026-10-27:
- CS50x weeks: https://cs50.harvard.edu/x/weeks/7/ (SQL), /8/ (HTML, CSS, JavaScript), /9/ (Flask).
- Odin Foundations sections: Git Basics, HTML Foundations, CSS Foundations, Flexbox, JavaScript Basics.

## Decision
- **Backbone:** CS50P L6 for M5.1, CS50x Week 7 for M5.3, Week 8 for M5.4, Week 9 for M5.5. They continue the CS50 style the student already knows, and Flask keeps the stack in Python.
- **Alternative for M5.4:** Odin Foundations (HTML, CSS, Flexbox, JavaScript Basics) for students who prefer project-based, more front-end-heavy material, or whose track is web-social.
- M5.2 (HTTP) and M5.6 (deployment) need resources chosen later.

## Consequences
- CS50x problem sets fall under the CS50 boundary (Duck only, [ADR 0005](0005-cs50-boundary-duck-mode.md)), so their fingerprints go into the B5 modules.
- Odin discourages AI for learning, which is compatible with L2 if the bot respects it during Odin lessons.
