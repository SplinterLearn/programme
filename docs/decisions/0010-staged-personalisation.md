# 0010. Personalisation is staged

**Status:** Accepted

## Context
Teens need the shared base (terminal, git, fundamentals, debugging, HTTP) before a specialism means anything, but autonomy matters for motivation from day one ([research report](../design/research-report.md), Q2).

## Decision
About **70/30 common/personal over the year as a whole**, not every week.
- **Months 1–4:** personalisation is the remix *theme* (track) and project choice.
- **From month 5:** dedicated track content grows to about half the time (Block 7, plus track-flavoured work in Blocks 5–6).

## Consequences
- Every remix offers several track variants. Two are fully tested at pilot (finance, fandom); others start brief-only.
- `tracks/<id>.md` describes each track's direction; `status: ready-for-pilot` marks the ones prepared first.
